## 1. 이 제품은 무엇인가 (디자인 관점)

인기 공연은 정해진 시각에 예매가 열리고 그 순간 최대 10만 명이 몰린다. 관객은 웹과 앱을
동시에 띄워 놓고 몇 초 차이를 다툰다 (`out/prd.md` §1).

> **가입은 버튼 한 번, 오픈은 같은 시계, 일행 자리는 한 번에.**

핵심 사람은 정민지(29, 회사원, 폰으로 예매)다. 이 사람에게 화면이 답해야 하는 질문은
"지금 몇 초 남았나(모든 기기에서 같은가)", "내 순번은 그대로인가", "3명이 붙어 앉을
자리가 어디 남았나"다. 화면의 정보 위계는 기능 목록이 아니라 이 질문 순서를 따른다.

## 2. 방향

**브랜드 색은 「누를 것」과 「지금 고를 수 있는 것」에만 쓴다.** 상태는 배지 6개로 말하고,
한 색은 한 뜻만 맡는다.

- 오픈 순간의 화면(상세·대기열·좌석)은 숫자가 주인공이다 — 카운트다운, 순번, 남은 연석.
  숫자는 `.num`(고정폭 숫자)으로 가장 크게 둔다.
- 오류는 문제 칸 바로 아래 또는 맨 위에 보이고, 해결 행동이 주 버튼이다.
- 끝난 상태(취소 완료·양도 완료·관람 완료)는 배지가 아니라 평문이다 — 배지는 관객이
  지금 무언가 해야 하거나 할 수 있는 상태에만 쓴다.

## 3. UI 라이브러리

| | |
|---|---|
| 라이브러리 | MUI (Material UI) — 근거 ADR-0002 |
| 기본값을 그대로 쓰는 범위 | 컴포넌트 구조(접근성·포커스 관리), 반응형 브레이크포인트 |
| 직접 정하는 것 | 색, 서체, 여백, 모서리, 그림자, 높이 — 전부 `design-tokens.css` 값 |

토큰은 MUI 테마에 주입한다 (`frontend/src/theme/`). 컴포넌트 코드는 테마만 참조한다.
MUI 의 8px `spacing` 스케일 대신 토큰 이름(`--page-x`·`--block-gap`·`--stack-s/m/l`
…)을 테마에 올려 쓴다. **토큰에 없는 색·여백·크기 값을 새로 만들지 않는다** — 필요하면
시안(`out/`)부터 고치고 토큰을 다시 옮긴다.

## 5. 의미 매핑

같은 뜻은 어디서나 같은 색·같은 말이다. **여기가 정본이다.**

| 의미 | 배지 클래스 | 화면에 쓰는 말 |
|---|---|---|
| 지금 살 수 있다 | `is-brand` | **예매 가능** |
| 아직 열리지 않았다 | `is-info` | **예정** |
| 좌석이 없다 | `is-danger` | **매진** |
| 기간이 지났다 · 공연이 취소됐다 | 기본(회색) | **마감** · **공연 취소** |
| 입금을 기다린다 | `is-warning` | **입금 대기** |
| 예매가 확정됐다 | `is-success` | **예매 확정** |
| 취소 완료 · 양도 완료 · 관람 완료 | (배지 없음, 평문) | 그대로 |

배지는 6가지를 넘기지 않는다. 새 상태가 생기면 기존 뜻에 묶거나 평문으로 쓴다.

### 말투

해요체 한 가지. 시안 문구를 그대로 쓴다 (예: "이메일 또는 비밀번호가 올바르지 않아요").
기능 문서의 문구와 시안이 다르면 시안이 이긴다.

## 6. 하지 않는 것

- 토큰에 없는 색·여백·크기 값을 화면 코드에 쓰기 (DESIGN-002·003)
- 같은 뜻에 다른 색, 한 색에 두 뜻 — §5
- 브랜드 색으로 CTA 외의 넓은 면 칠하기
- 한 화면에 주 버튼 둘 — 해결 행동 하나만 주 버튼
- 끝난 상태에 배지 달기
- 시안에 없는 배너·쿠폰·남은 시간 띠 넣기 (`out/screens.json` 의 `promos` 가 비어 있다)

## 7. 품질 하한선

취향이 아니라 하한선이다. Phase 4 에서 확인한다.

- [ ] 375px 폭에서 가로 스크롤이 없다
- [ ] **같은 화면의 시안(`out/screens/<id>.html`)과 나란히 띄워 구조·문구·색이 같다**
- [ ] 키보드 포커스가 눈에 보인다 (`--c-focus`)
- [ ] `prefers-reduced-motion` 을 존중한다
- [ ] 본문 대비 4.5:1 이상
- [ ] `<html lang="ko">` — 콘텐츠 언어와 일치
- [ ] `<title>` 이 템플릿 기본값이 아니다
- [ ] Pretendard 가 실제로 로드된다 (선언만 하고 로드하지 않으면 폴백된다)
- [ ] 누르는 것은 전부 어딘가로 가거나 결과를 알린다 (시안의 `href`·`data-back`·`data-stay`)
