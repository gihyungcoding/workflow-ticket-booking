# 디자인 방향

**최종 갱신**: 2026-09-09

---

## 1. 이 제품은 무엇인가 (디자인 관점)

소규모 공연 예매다. 대형 예매처가 아니라, **전화와 메신저로 예매를 받고 좌석을 수기로
관리하던** 주최자의 공연이다 (product.md §2).

지금 만든 화면(TASK-001·002)의 청중은 **관객**이고, 이 화면의 주된 일은 하나다.

> **"지금 이 공연을 살 수 있는가"에 연락 없이 답한다.**

product.md §5 성공 기준이 그대로 이것이다 — *"관객이 문의 없이 예매 가능 여부를 확인한다"*.

## 2. 방향

**대담함은 상태 하나에만 쓴다. 나머지는 전부 조용하다.**

화면에서 채도가 있는 색은 「예매가능」 하나뿐이다. 목록을 훑을 때 지금 살 수 있는
공연만 눈에 들어와야 한다.

### 왜 다섯 색이 아닌가

관객에게 상태는 다섯이 아니라 셋이다.

```
살 수 있다    OPEN
아직이다      UPCOMING
못 산다       SOLD_OUT · CLOSED · CANCELLED     ← 결과가 같다
```

다섯에 모두 색을 주면 다섯이 똑같이 시끄럽고, 주된 일이 묻힌다.

### 물러남은 채도를 빼는 것이지 흐리게 하는 것이 아니다

예매할 수 없는 공연도 **왜 못 사는지는 읽혀야 한다.** 그래서 물러난 상태의 텍스트도
대비 4.5:1을 지킨다 (`--color-ink-faint` 4.80:1). 명도를 낮춰 흐리게 만들지 않는다.

## 3. UI 라이브러리

| | |
|---|---|
| 라이브러리 | MUI (Material UI) v9 — 근거 ADR-0002 |
| 기본값을 그대로 쓰는 범위 | 컴포넌트 구조, 간격 스케일(8px), 반응형 브레이크포인트 |
| 직접 정하는 것 | 색, 서체, 모서리, 그림자 유무, 상태 표현 |

토큰은 `design-tokens.css` 에 두고 MUI 테마에 주입한다. 컴포넌트 코드는 테마만 참조한다.

## 4. 토큰

정본은 `docs/product/design-tokens.css` 다. 여기는 **왜 그렇게 정했는지**만 적는다.

| 축 | 결정 | 왜 |
|---|---|---|
| 색 | 잉크(청회색) + 무채색 표면 + 별색 1도 | 공연 인쇄물의 관행이 검정 잉크 + 별색 1도다. 별색을 「예매가능」에 배정하면 그 관행이 그대로 주된 일을 푼다 |
| 잉크 | `#1A2027` — 순검정도 `#0B0B0B` 류도 아님 | 순검정은 화면에서 과하고, 틴티드 니어블랙은 생성된 페이지의 흔한 표식이다 |
| 배경 | `#F7F8F9` — 크림 아님 | 크림(#F4F1EA) + 세리프 + 테라코타 조합은 AI 생성물의 가장 흔한 인상이다 |
| 별색 | 딥 그린 `#0E6E52` | 「가능」을 직관적으로 뜻해 학습이 필요 없다. MUI 기본 success(#2E7D32)보다 깊게 잡아 기본값 인상을 피한다 |
| 타이포 | 공연명만 명조(Noto Serif KR), 나머지 고딕(IBM Plex Sans KR) | 공연 포스터의 어휘. **한 곳에만** 써서 공연명이 화면의 주인이 되게 한다 |
| 간격 | MUI 기본 8px 유지 | 바꿀 근거가 브리프에 없다. 바꾸면 기존 `spacing={n}` 이 전부 비례 변경된다 |
| 형태 | 그림자 없음, 모서리 2px | 위계는 선과 여백으로 만든다. 동일한 둥근 카드에 같은 그림자를 까는 것은 기본값이다 |

**서체는 한글 음절 범위(U+ac00–d7a3)를 실제로 포함하는지 확인했다.** Inter·Playfair
Display·Space Grotesk 처럼 흔히 추천되는 서체는 한글이 없어 시스템 폰트로 폴백되고,
그러면 여기서 정한 것이 화면에 나타나지 않는다.

## 5. 의미 매핑

같은 뜻은 어디서나 같은 색·같은 말이다. **여기가 정본이다.**

| 의미 | 색 역할 | 화면에 쓰는 말 | 처리 |
|---|---|---|---|
| 살 수 있다 | `--color-open` | **예매가능** | 별색 배지. 화면에서 유일한 채도 |
| 아직이다 | `--color-ink-muted` | **예매예정** | 윤곽선 배지, 채도 없음 |
| 좌석이 없다 | `--color-ink-faint` | **매진** | 회색 배지 + 행 전체가 물러남 |
| 기간이 지났다 | `--color-ink-faint` | **예매마감** | 위와 같음 |
| 공연이 취소됐다 | `--color-ink-faint` | **공연취소** | 위와 같음 |

### 문구를 고친 이유

| 전 | 후 | 왜 |
|---|---|---|
| 예정 | 예매예정 | 공연이 예정인지 예매가 예정인지 모호했다 |
| 마감 | 예매마감 | 무엇이 마감인지 말하지 않았다 |
| 취소 | 공연취소 | 내 예매가 취소된 것으로 읽힐 수 있었다 |

빈 화면과 오류는 다음 행동을 제시한다.

| 상황 | 문구 |
|---|---|
| 목록 비었음 | 예정된 공연이 없습니다 |
| 목록 실패 | 목록을 불러오지 못했습니다 · `[다시 시도]` |
| 상세 없음 | 존재하지 않는 공연입니다 · `[목록으로]` |

## 6. 하지 않는 것

기본값이라서 나오는 것들이다. 브리프가 요구하지 않으면 쓰지 않는다.

- 상태를 다섯 색으로 표현하기 — §2 가 이 문서의 핵심이다
- 동일한 둥근 카드 + 같은 그림자로 목록 만들기
- 카드마다 hover 트랜지션, 섹션마다 fade-and-slide-up
- 제목에서 한 단어만 색·굵기로 강조하기
- 라벨을 ALL-CAPS 로 쓰기, 자간을 벌린 머리말 라벨
- 버튼·링크 텍스트 뒤에 `→` 붙이기
- 순서가 아닌 것에 01 / 02 / 03 번호 매기기
- 크림 배경 + 테라코타 액센트, 보라·청록 그라디언트

## 7. 품질 하한선

취향이 아니라 하한선이다. Phase 4 에서 확인한다.

- [ ] 모바일까지 반응형
- [ ] 키보드 포커스가 눈에 보인다
- [ ] `prefers-reduced-motion` 을 존중한다
- [ ] 본문 대비 4.5:1 이상 — **물러난 상태 텍스트 포함**
- [ ] `<html lang="ko">` — 콘텐츠 언어와 일치
- [ ] `<title>` 이 템플릿 기본값이 아니다
- [ ] 서체가 실제로 로드된다 (선언만 하고 설치하지 않으면 폴백된다)
